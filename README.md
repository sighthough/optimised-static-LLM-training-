Step-by-Step Training ProtocolPhase 1: Isolated Layer 1 Optimization (Active Stack: Layer 1)Objective: Establish a foundational feature representation using only the first hidden layer while isolating it from upper-layer noise.Steps:Forward Pass & Routing: The network routes inputs exclusively through Hidden Layer 1 and directly to the output layer, limiting active parameters to 49.Initial Training: Optimization begins with a base learning rate ($\text{LR} = 0.0300$).Peak Checkpointing: As the model trains, the loss tracker monitors performance.
